### 2. What to Do & How to Do It (The Blueprint)

#### Step 1: Data Scraping (The Foundation)

* **The Challenge:** Real estate sites load dynamically.
* **The Solution:** Use **Playwright** (Python). It is faster and more modern than Selenium.
* **How:**
* Scrape text content like property descriptions, FAQs, company "About Us" pages, and location details.
* Clean the data (remove HTML tags, fix spacing) and save it to a structured format like JSON or CSV.
* *Pro Tip:* Respect `robots.txt` and add a small delay (e.g., 1-2 seconds) between page requests to avoid getting IP banned.

#### Step 2: Building the RAG Pipeline (The Brains)

You need to build a Retrieval-Augmented Generation (RAG) system so the chatbot actually uses the scraped data.

* **Embeddings:** Since you are using a free setup, do not use OpenAI embeddings. Use locally hosted free embeddings via HuggingFace `sentence-transformers` (e.g., `all-MiniLM-L6-v2`). It runs perfectly on CPU.
* **Vector Database:** Use **FAISS** (by Meta) or **ChromaDB**. FAISS is highly recommended because it is strictly in-memory, incredibly fast, and very lightweight for free-tier deployments.
* **Chunking:** Use LangChain or LlamaIndex's `RecursiveCharacterTextSplitter` to chunk the scraped data (e.g., chunk size 500, overlap 50) before embedding.

#### Step 3: LLM Integration (OpenRouter)

OpenRouter provides an OpenAI-compatible API that aggregates dozens of models, many of which have robust free tiers.

* **Model Choice:** Use **Meta Llama 3 (8B Instruct)** or **Mistral 7B Instruct**. They are frequently free on OpenRouter and offer top-tier performance for their size.
* **How:** Use LangChain's `ChatOpenAI` wrapper and point the base URL to OpenRouter.

```python
from langchain_openai import ChatOpenAI
llm = ChatOpenAI(
    openai_api_key="YOUR_OPENROUTER_KEY",
    openai_api_base="https://openrouter.ai/api/v1",
    model_name="meta-llama/llama-3-8b-instruct:free"
)
```
